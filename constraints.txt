# Pinned dependency versions for reproducible builds.
#
# backend/requirements.txt and pyproject.toml declare open lower bounds so the
# package stays installable alongside other software. That is wrong for a
# deployment: `docker build` on two different days would produce two different
# images, and a major release of FastAPI or Pydantic would break production at
# build time with no code change on our side.
#
# Install with:   pip install -r backend/requirements.txt -c constraints.txt
#
# These versions are the ones the test suite is verified against. To upgrade:
# bump here, run `pytest tests/`, rebuild the image, and commit together.
